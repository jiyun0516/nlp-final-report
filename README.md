# KoNLPy 형태소 분석기 비교

KoNLPy의 **Komoran**과 **Okt**를 활용하여 한국어 불규칙 용언의 형태소 분석 성능을 비교한 프로젝트입니다.

## 프로젝트 개요

한국어의 불규칙 용언은 활용 과정에서 어간이나 어미의 형태가 변하기 때문에 정확한 형태소 분석이 어렵습니다.  
본 프로젝트에서는 `ㅅ`, `ㄷ`, `ㅂ`, `르`, `우`, `여`, `러`, `ㅎ` 불규칙 용언을 대상으로 Komoran과 Okt의 분석 결과를 비교했습니다.

## 기술 스택

- Python
- KoNLPy
- Komoran
- Okt
- JPype1

## 분석 방법

각 불규칙 유형이 포함된 예문을 Komoran과 Okt의 `pos()` 메서드로 분석하고, 활용형의 어간과 어미가 올바르게 분리되는지 비교했습니다.

| 불규칙 유형 | 분석 대상 | Komoran | Okt |
|---|---|:---:|:---:|
| ㅅ | 지었다 | ❌ | ❌ |
| ㄷ | 걸었다 | ✅ | ❌ |
| ㅂ | 구워먹는다 | ✅ | ❌ |
| 르 | 흘러 | ✅ | ❌ |
| 우 | 퍼 | ✅ | ❌ |
| 여 | 연습하여라 | ✅ | ❌ |
| 러 | 이르러 | ✅ | ❌ |
| ㅎ | 파래 | ❌ | ❌ |

## 결과

Komoran은 8개의 불규칙 유형 중 **6개 유형을 올바르게 분석**했으며, Okt는 실험 대상의 불규칙 활용에서 어간과 어미를 정확하게 분리하지 못했습니다.

이를 통해 본 실험에서는 **Komoran이 Okt보다 한국어 불규칙 용언의 형태소 분석에 더 적합한 결과를 보임**을 확인했습니다.
